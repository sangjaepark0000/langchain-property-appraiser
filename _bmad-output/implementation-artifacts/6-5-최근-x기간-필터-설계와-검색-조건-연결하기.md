Status: review

## Story

As a 사용자,
I want 최근 X기간 안에 변경된 자료를 기준으로 질문하고 싶다,
so that 오래된 자료와 최근 변경사항을 구분해 검토할 수 있다.

## Acceptance Criteria

1. official documents에 개정일 또는 시행일 metadata가 있으면 최근 X기간 필터를 검색/후처리 조건으로 사용할 수 있고 어떤 날짜 필드 기준인지 표시한다.
2. 날짜 metadata가 부족하면 필터 적용 제한을 알리고 부족한 날짜를 임의 생성하지 않는다.
3. “최근 1년” 같은 자연어를 구조화된 filter 후보로 변환할 수 있고, 불확실하면 제한/확인 필요 상태를 제공한다.
4. 수동 보완/에이전트 한계/사전 작업은 날짜 metadata 품질 기준으로 문서화한다.
