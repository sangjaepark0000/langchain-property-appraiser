# Story 6.6: 알림 레벨을 작업 우선순위로 정의하기

Status: review

## Story

As a 사용자,
I want 변경사항의 알림 레벨을 법적 판단이 아니라 작업 우선순위로 보고 싶다,
so that 시스템 답변을 위법/적법 판단으로 오해하지 않을 수 있다.

## Acceptance Criteria

1. 알림 레벨은 high/medium/low 작업 우선순위로 표현되고 위법/적법/법적 책임 판단으로 표현되지 않는다.
2. 알림 레벨 산정 근거가 부족하면 낮은 신뢰도 또는 추가 확인 필요를 표시하고 확정 판단을 만들지 않는다.
3. “왜 high야?” 설명은 검색 근거, 날짜 조건, 출처 기반 이유를 설명하고 최종 전문/법률 판단은 사용자 책임임을 유지한다.
